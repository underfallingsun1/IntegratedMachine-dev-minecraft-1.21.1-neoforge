# Integrated Machine

---

## What`s this

this is a mod of [minecraft][mc] developed by [neoforge][nf]. the lastest version
is based on minecraft `1.21.1` and neoforge `21.1.250`. This mod add lots of
useful and highly customizable multiblock machines for the game. this mod still
in its early development.

## How to use it

this mod is used just like normal neoforge mod. You can follow this guide to
add this mod to your game.

- [Download minecraft `1.21.1`. ][mc]
- [Download neoforge and apply it to your minecraft game][nf]
- Note: most minecraft launcher such as [PCL2](https://pcl.ruanmao.net/) can do this automatically
- run the game and then put the mod in the `mod/` folder in the game folder
